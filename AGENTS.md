# AGENTS.md - Guidance for AI Agents

## Critical Rules

- **Follow ASD-STE100 writing guidelines** for your prose and documentation.
- **NEVER push directly to `master`** - Any change must be done through a
  patch with a new branch. Create a feature branch, commit your changes,
  and open a PR.
- **NEVER use `/` in branch names** - Use `-` or `_` as separators instead.
- **Keep PRs small and reviewable.** One branch and one PR per logical
  unit of work.
- **Add a CHANGELOG entry for every PR, in its own commit.** The changelog
  entry MUST always be a separate commit from the code it describes.
- **When cutting a tag/release, the CHANGELOG MUST be updated in the same
  PR.** Move the entry from `[Unreleased]` to the version heading.
- **Record the model in the commit message and the PR.** A trailing line
  such as `Model: <provider>/<model-id>`.
- **Do not reference plan or task numbers in commits, PRs, or the changelog.**
- **Verify the full CI pipeline is green before considering a branch done.**

## Security

- **NEVER add any new dependency or update a dependency** without the
  explicit consent of the prompt engineer.

## Cross-Repo Impact

This module is consumed by **both** an internal consumer and a scanner tool.
Schema changes (adding/removing/renaming fields in `L9Event`, changing the
plugin interface) require coordination with both consumers. Bump the version
and update both repos' `go.mod` in separate PRs.

## Key Architectural Patterns

### L9Event

The `L9Event` struct is the canonical leak event schema. Fields are
serialized to JSON with `json` tags. The `l9event.json` file is the
JSON Schema (generated by `cmd/genjson`).

### Plugin Interface

`ServicePluginInterface` is the interface that scanners implement. It has:
- `Name() string` - Plugin identifier
- `Init() error` - Optional initialization
- `Run(ctx, event, options) bool` - Produce a leak verdict
- Optional tags filtering

`WebPluginInterface` is the interface for web-based scanners.

### Fingerprint

`UpdateFingerprint()` computes a 32-char hex fingerprint from the event
source, URL, and summary. The first 28 chars are the prefix (used for
deduplication), the last 4 are the fnv32 hash.
